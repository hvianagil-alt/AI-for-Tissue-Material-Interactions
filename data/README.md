# Dataset

`hydrogel_chondrocyte_records.csv` is generated by:

```bash
python -m tissuelab.build_dataset
```

It concatenates:

1. `src/tissuelab/literature.py` — curated records from published hydrogel–chondrocyte studies.
2. `src/tissuelab/simulator.py` — literature-informed synthetic records.

Do not treat simulator rows as experimental observations. They exist so the software stack (schema → model → inverse design → UI) can run before a 500–5,000 row curated corpus exists.
